# Noname Launcher

Launcher Android minimalis (home app) — Kotlin + Jetpack Compose, minSdk 36 (Android 16).

Dibangun tanpa Android Studio: tulis kode di **Termux**, build otomatis lewat **GitHub Actions**.

## Mulai cepat

Buka **`PANDUAN.md`** dan ikuti langkahnya dari atas ke bawah.

## Fitur v1

- Menjadi home screen (tombol HOME membuka Noname)
- Wallpaper sebagai latar
- Grid ikon semua aplikasi (4 kolom), tap untuk membuka
- Swipe up -> drawer + pencarian aplikasi
- Long-press ikon -> Info aplikasi / Hapus
